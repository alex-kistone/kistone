# Kistone connect

Je suis dirigeant du cabinet Gotam. Nous plaçons des recruteurs indépendant en mission chez nos clients.
J'aimerais créer un dashboard en ligne qui permettrait aux freelance de s'inscrire et me transmettre leur profil avec :
- Photo
- Leurs compétences clés
- Lien LinkedIN
- Les clients majeurs qu'ils ont accompagnés
- TjM (tarif journalier moyen
- Modèle RPO ou succès
- Date de disponibilité

L'idée serait que chacun puisse compléter son profil et ainsi alimenter ma base de donnée
Dans mon interface, je peux classer, filtrer, rechercher les profils comme dans un ATS/CRM
